# BLK_MEDIA

A single finished clip shown for review — video, image, or audio — with optional variants and confirm/regenerate actions.

## When to use
- One finished render is ready for approval or a next step.
- Showing prior takes of the SAME shot via `variants` (a variant strip).

## When NOT to use
- 1–6 still images for review or comparison — use `gallery`.
- A composed visual direction (mixed tiles + palette) — use `moodboard`.

## Author checklist
- Pass a URL from a tool result THIS turn or from PROJECT MEMORY assets — never invent one.
- Pair with 2–4 `actions` to advance (Approve / Regenerate / Try a different model).
- Use `mediaKind: "image"` only for a single reviewable still (use `gallery` for sets).
