# BLK_STORYBOARD

Cinematic shot-by-shot storyboard — one slide per shot, navigable with a progress strip. This is the canonical shape for beat breakdowns and shot lists.

## When to use
- Presenting a beat list / shot list for review before render.
- Any per-shot breakdown with metadata (Shot N · Xs), a short title, a visual prompt, and optionally a VO line.

## When NOT to use
- Flat list without per-shot ceremony — use `list`.
- Reviewing generated stills — use `gallery`.

## Author checklist
- Every slide gets a big display title (≤6 words).
- Include `vo` only when a voiceover line is actually planned for the shot.
- Pair with 2–4 `actions` (Lock it in, Rework a beat, Different structure).
