# BLK_GALLERY

1–6 still IMAGES shown for review or comparison — scene anchors, character concepts, style references. Layout is automatic (1 centered, 2–3 across, 4–6 wrap).

## When to use
- Reviewing one anchor or concept image.
- Comparing 2–6 alternatives the user might name (add a short `label` on each).

## When NOT to use
- A finished video/audio clip — use `media`.
- A forced pick of EXACTLY ONE image (mutually exclusive) — use `options` with `image` visuals.
- A composed direction (mixed image + palette + type tiles) — use `moodboard`.

## Author checklist
- Every URL must come from a tool result THIS turn or PROJECT MEMORY assets.
- Pair with 2–4 shared `actions` (Approve, Regenerate, Try again).
