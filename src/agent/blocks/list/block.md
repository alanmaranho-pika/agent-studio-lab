# BLK_LIST

Plain ordered list of short items (up to 12). Only for genuinely flat data — checklists, options summaries, exports queue.

## When NOT to use
- Shot lists / beat breakdowns — use `storyboard` (one slide per shot).
- Ranked choices the user should pick from — use `options`.

## Author checklist
- Each item has an optional `meta` eyebrow and up to 280 chars of text.
- Pair with `actions` only when the whole list has a shared next step.
