# BLK_MOODBOARD

ONE composed visual direction shown as a masonry collage — mixed image tiles, one palette tile, optionally a type-specimen tile. Presents a single style for sign-off.

## When to use
- Proposing a style / vibe / world for lock-in.
- 4–8 labeled image tiles, usually with one palette (3–6 hexes pulled from the imagery), optionally one type tile.

## When NOT to use
- Comparing several alternative directions — use `gallery` or `options`.
- A single anchor image for review — use `gallery`.

## Author checklist
- Label every image tile with what it contributes (Costume / Landscape / Texture).
- Include lock/rework `actions` so the user can accept or ask for another pass.
